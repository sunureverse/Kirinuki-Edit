Kirinuki-Edit 사용 안내

1. 처음 받은 폴더라면 docs/windows-setup.md의 설치 안내를 따르세요.
   필요한 도구를 설치한 뒤 install-windows.cmd를 한 번 실행합니다.
   GitHub ZIP에는 설치 환경, 모델, 개인 영상과 편집 데이터가 포함되지 않습니다.

2. 설치 후에는 '대시보드 실행.cmd' 또는 start-dashboard.cmd를 두 번 클릭하세요.
   실행된 검은 창은 편집하는 동안 열어 두세요.
   사용자 편집 → 제목 버튼에서 상단 제목을 고칠 수 있습니다.
   작업 후 저장 버튼 또는 Ctrl+S를 누르세요.

3. 내 작업이 저장되는 곳
   projects : 저장된 프로젝트와 가져온 영상
   edit : 컷, 자막, 화면 배치, 미리보기와 작업 기록
   jobs : Codex에 요청한 작업 지시문
   analysis-library : 영상별 대사, 하이라이트 후보와 확인 기록
   이 폴더들은 작업할 때 생성되며 GitHub에는 올리지 않습니다.

4. 프로그램이 사용하는 폴더
   dashboard, shortsmith, tools : 프로그램 파일
   venv, local-fonts : 설치 환경과 글꼴
   docs : 설명서
   PROGRESS.md : 과거 개발 기록

5. 작업 순서
   영상을 Codex에 전달 → 하이라이트 후보 확인 → 원하는 구간 선택
   → 번역과 한국어 자막 편집 → 미리보기 확인 → 완성 영상 렌더 요청
   분석 보관함은 Codex가 관리하며 대시보드 자동 분석 기능은 아닙니다.
   GPU 받아쓰기는 별도 도구가 준비된 PC에서만 사용할 수 있습니다.
   GitHub 다운로드만으로 GPU 도구가 자동 설치되지는 않습니다.

6. 백업과 업데이트
   저장 후 대시보드를 종료하고 작업 폴더와 외부 원본 영상을 백업하세요.
   영상 이름이나 위치를 바꾸면 연결이 끊길 수 있습니다.
   GitHub는 개인 편집 작업의 백업을 대신하지 않습니다.
   새 ZIP을 받았다고 기존 projects/edit 폴더를 삭제하지 마세요.

자세한 설명: docs/windows-setup.md, docs/대시보드_가이드.md,
             docs/analysis-library.md
