# 영상 분석 재사용

사용자는 영상을 주고 후보를 선택하면 됩니다. 아래 명령과 자료 관리는 Codex가 담당합니다.

영상별 `analysis-library/<SHA256>/`에 대사, 후보, 확인 기록, 선택 기록을 모읍니다. 원본 영상은 복사하지 않습니다. 같은 내용의 영상은 이름이 달라도 같은 보관함을 사용합니다. 영상 내용이 바뀌면 다른 보관함을 만듭니다. 최초 등록 시 전체 파일을 읽어 SHA-256을 계산하므로 큰 영상에서는 시간이 걸립니다. 등록 후에는 저장된 경로·크기·수정 시각을 먼저 검사하고, 변경 시 내용을 다시 검사합니다. 크기와 수정 시각을 의도적으로 모두 유지한 변조를 탐지하는 기능은 아닙니다.

## 순서

1. 작업 JSON의 mediaPaths 또는 사용자가 제공한 실제 영상 경로를 확인합니다. 기존 보관함의 source.json을 찾아 원본과 대사를 먼저 확인합니다.
2. 처음 보는 영상만 ffprobe로 길이를 확인하고 등록합니다.
   `python tools/analysis_library.py init "영상 경로" --duration 144.95`
   출력된 폴더 경로를 이후 명령의 `<보관함>`으로 사용합니다.
3. 기존 전사가 있으면 가져옵니다. 없을 때만 AGENTS.md의 기존 GPU 도구로 일본어 전사를 수행합니다.
   `python tools/analysis_library.py import-transcript "<보관함>" "기존 전사.json"`
   구간을 잘라 전사하여 시각이 구간의 0초부터 시작할 때만 `--offset 시작초`를 지정합니다. 이미 제공 영상 기준인 결과에는 더하지 않습니다. 원본 방송 시각과 추출 영상 시각을 혼동하지 마세요.
4. 실제 확인 후 후보와 확인 기록을 JSON으로 작성하여 등록합니다.
   `python tools/analysis_library.py record "<보관함>" "기록.json"`
5. `python tools/analysis_library.py report "<보관함>"`로 사람이 읽는 summary.md를 갱신하고 사용자에게 후보를 전달합니다.
6. 사용자가 후보를 고르면 selection 기록에 해당 요청을 근거로 남기고, 저장된 대사·확인 기록을 읽어 선택 구간만 번역·편집합니다. 선택하지 않은 구간의 한국어 자막을 미리 완성하지 않습니다.

## 기록 예시

```json
{"kind":"candidate","id":"candidate-01","start":28.5,"end":106.35,"note":"놀림부터 당황한 뒤의 반응까지 포함하는 후보","basis":"실제로 확인한 장면과 근거 파일을 기록"}
```

`review`는 `mode`가 필요합니다: `audio`, `video`, `audio-video`, `historical-record`. 확인한 범위만 start/end로 기록합니다. 과거 문서를 가져온 것은 historical-record이며 새로 영상을 확인했다고 쓰지 않습니다.

`selection`에는 `candidateId`가 필요합니다. 사용자가 실제로 선택했을 때만 기록하며, basis에 사용자 요청을 남깁니다. 모든 기록에는 id, start, end, note, basis가 필요합니다. 기존 기록을 덮어쓰지 않으며 수정 판단은 새 id와 이전 기록을 언급한 근거로 남깁니다.

## 파일과 주의점

- source.json: 영상 식별 정보, 경로, 길이. 모든 시각은 제공 영상 기준 초입니다.
- transcripts/: 대사·단어 시각을 복사한 독립 자료. 원본 전사는 변경하지 않으며, 같은 전사와 오프셋의 중복 등록을 방지합니다. 기본은 미검수 상태입니다.
- records/: 후보, 확인, 선택 기록. 선택 결과나 과거 결론을 덮어쓰지 않습니다.
- summary.md: 읽기 쉬운 요약. 대사 범위 사이에 분석하지 않은 구간이 있을 수 있습니다.

ASR의 flaggedBlocks와 별도 품질 기록은 원래 자료도 확인하여 review에 근거를 남기세요. 가져오기만으로 오류가 교정되거나 전체 영상 확인이 완료되지는 않습니다. 이 도구는 받아쓰기·하이라이트 탐색·번역을 자동 수행하지 않고 그 결과를 보관하고 재사용합니다. 대시보드 버튼에는 아직 연결하지 않았습니다.

보관함에는 개인 영상 경로와 대사가 있어 GitHub 업로드에서 제외합니다. 로컬 백업에는 analysis-library 폴더도 포함하세요.
